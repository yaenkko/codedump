# codedump

Sammlung kleiner Projekte zum Selbst-Programmieren-Lernen.

## Aktuelles Projekt

- **[PersonalWikiPy](PersonalWikiPy/)** – ein lokales, persönliches Wiki für
  Windows 11 (Python / Tkinter). Läuft als `.exe`, mit **Anmeldung**,
  **Admin-Nutzer**, mehreren Nutzern mit **eigener Library** und **Freigaben**
  untereinander. Inhalte werden als Markdown-Dateien in Ordnern gespeichert.
  Siehe [PersonalWikiPy/README.md](PersonalWikiPy/README.md).
